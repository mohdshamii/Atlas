Data Sources & Provenance

India Data Atlas is built so every number carries an honest, audited provenance status. This page defines what those statuses signify and lists the official government ministry datasets mapped to each of the 11 locked indicators.

This build uses deterministically calibrated demo data

No verified government survey microdata has been finalized into this release build. Every displayed figure is derived deterministically from seeded pseudo-random algorithms for continuous illustration and marked DEMO or NO DATA. The data service layer (`core/data_service.py`) is decoupled so live production databases (PostgreSQL/SQLAlchemy/API) can be connected without touching any template or UI logic.

Status Definitions

VERIFIED

Official Dataset

Directly sourced from cited, verifiable government surveys (Census, UDISE+, HMIS, PLFS) with recorded observation timestamps.

DEMO DATA

Deterministically Generated

Calculated using seeded Mulberry32 PRNG algorithms across district baselines. Stable across reloads and device viewports.

UNAVAILABLE

Missing Observation

Neither verified nor simulated observation exists for that metric/year, exercising empty-state handling in UI controls.

Notes on GeoJSON Boundaries

District polygons shown on the interactive maps are generated bounded Voronoi tessellations derived from hand-estimated district centroids, created specifically as a visualization aid. They do not constitute official administrative survey boundaries and must not be used for legal or jurisdictional purposes.
